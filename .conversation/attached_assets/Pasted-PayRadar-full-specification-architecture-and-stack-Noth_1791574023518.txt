PayRadar: full specification, architecture and stack

Nothing here has been run or tested. Treat the code as skeletons to verify. Pin your own library versions when you install.

1. What PayRadar is

One line: a cash-flow early-warning and decision tool for Indian MSMEs. It predicts when each customer will actually pay, forecasts the bank balance with uncertainty, and tells the owner which dues to chase and which vendor payments to make first to avoid statutory interest or a Section 43B(h) tax disallowance.

User: the owner or accountant of a small firm that sells on credit to larger buyers and also buys from micro and small vendors.

Problem (evidence from my research):

Payment cycles average 73 days (Recordent, Jun 2026).
Samadhaan has ₹20,979 crore pending (Crisil, Aug 2026).
Statutory interest is 3× the Bank Rate. The Bank Rate became 5.75% on 7 Oct 2026, so the rate is 17.25%, compounded monthly.

What makes it different from reminder tools: it forecasts uncertain payment dates and cash balance, and it works on both sides of the ledger (receivables and payables).

6. Core logic
6.1 Statutory engine (statutory.py)

Rules, as I understand them from the sources (have an accountant verify):

Appointed day: if there is a written agreement, acceptance date plus agreed days, capped at 45 days. With no agreement, 15 days after acceptance.
Interest: starts the day after the appointed day, at 3× the Bank Rate in force, compounded with monthly rests. Section 23 makes this interest non-deductible for the buyer.
43B(h): the buyer’s deduction is disallowed for the year if the amount to a registered micro or small supplier is still unpaid at year end (31 March) beyond the limit. It is allowed in the year of actual payment.
Applicability: only registered micro and small suppliers. Medium suppliers are not covered, which is why the toggle matters.

Skeleton:

python
import pandas as pd
from datetime import date, timedelta

def appointed_day(accept: date, agreed_days: int | None) -> date:
    days = 15 if not agreed_days else min(agreed_days, 45)
    return accept + timedelta(days=days)

def bank_rate_on(d: date, rates: pd.DataFrame) -> float:
    # rates: columns effective_from (date), bank_rate (percent)
    r = rates[rates.effective_from <= d].sort_values("effective_from")
    return float(r.iloc[-1].bank_rate)

def section16_interest(principal, appointed: date, until: date, rates) -> float:
    """Monthly-rest compounding at 3x bank rate. Assumption: whole months
    compound; the final partial month accrues pro-rata. Verify with a CA."""
    if until <= appointed: return 0.0
    amt, cur = principal, appointed
    while cur < until:
        nxt = min(cur + pd.DateOffset(months=1), pd.Timestamp(until)).date()
        frac = (nxt - cur).days / 30.0
        rate = 3 * bank_rate_on(cur, rates) / 100.0
        amt += amt * rate / 12.0 * frac
        cur = nxt
    return round(amt - principal, 2)

def disallowance_exposure(amount, appointed: date, paid: date | None, fy_end: date, tax_rate):
    unpaid_at_ye = (paid is None) or (paid > fy_end)
    return amount * tax_rate if unpaid_at_ye and appointed <= fy_end else 0.0

6.2 Buyer behavior model (behavior.py)

For each paid invoice: days_to_pay = paid_date - invoice_date. Model log(days) as normal.

Global prior: (mu_g, sd_g) from all paid history.
Shrinkage per buyer: with n paid invoices and k = 3,
mu_b = (n*mean_b + k*mu_g)/(n+k), and the same blend for sd_b.
Open invoice of age a: it hasn’t been paid yet, so sample log(d) from the normal truncated below at log(a). That is the censoring correction.
python
import numpy as np
from scipy.stats import truncnorm

def fit(history):  # history: df with buyer, days_to_pay
    logd = np.log(history.days_to_pay.clip(lower=1))
    mu_g, sd_g = logd.mean(), logd.std(ddof=1)
    params, k = {}, 3
    for b, g in history.assign(l=logd).groupby("buyer"):
        n = len(g)
        mu = (n*g.l.mean() + k*mu_g)/(n+k)
        sd = max(((n*g.l.std(ddof=1 if n>1 else 0) + k*sd_g)/(n+k)), 0.15)
        params[b] = (mu, sd)
    return params, (mu_g, sd_g)

def sample_days(buyer, age, params, prior, size, rng):
    mu, sd = params.get(buyer, prior)
    a = (np.log(max(age,1)) - mu)/sd
    return np.exp(truncnorm.rvs(a, np.inf, loc=mu, scale=sd, size=size, random_state=rng))

Honest limitation: this ignores amount, season and month-end effects. Say so; list covariates as a roadmap item.

6.3 Cash forecast (forecast.py)
Simulate N≈2000 paths over 60 days.
Each open receivable arrives on invoice_date + sampled_days (drop it if beyond the horizon).
Payables follow a policy, such as “pay on appointed day” versus the recommended schedule.
Daily balance = opening + cumulative receipts − cumulative payments.
Output: P10/P50/P90 per day, and P(balance < min_cash_buffer) per day.
Headline metric: the first day with shortfall probability above 20%.
6.4 Action ranker (actions.py)
Chase list (receivables):
priority = amount × P(arrives later than horizon) × (1 + statutory_interest_accrued/amount)
Pay-first list (payables to MSE vendors):
cost_of_missing = tax_rate×amount (if year-end crossed) + projected interest; urgency = cost_of_missing / max(days_to_deadline,1)
Greedy schedule: sort by urgency, pay while the simulated P10 balance stays above the buffer. If a must-pay doesn’t fit, flag a shortfall and suggest chasing the top receivables or discounting (generic suggestion only, no integration).
6.5 LLM layer (llm.py)

Three calls:

Column mapping: send headers plus 5 sample rows, get back JSON {"buyer":"Party Name", ...}. Validate against the schema in code. If it fails, fall back to a manual dropdown.
Explanation: input is the action’s JSON (numbers and reasons). The prompt forbids introducing any number not in the JSON.
Notice draft: polite or firm tone, with interest figures passed in. It ends with a “draft, not legal advice” line.

Number validator (required): extract all numbers from the output with a regex. If any isn’t in the allowed set (allowing formatting variations), reject and regenerate once, then fall back to a template.

Appointed day: with agreement, without, and capped at 45.
